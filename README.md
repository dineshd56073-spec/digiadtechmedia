# DigiAdTechMediaTN

Official website and digital marketing platform for **DigiAdTechMediaTN.com** — providing practical Google Ads training in English & Tamil, Google Business Profile services, campaign management, and website development.

---

## 🌟 Key Features

- **Google Ads 4-Month Practical Curriculum** (Fundamentals, Search Ads, Optimization, Certification)
- **Bilingual Learning**: English + Tamil explanations
- **Google Business Profile & SEO**
- **Lead Generation & WhatsApp Direct Integration** (`+91 96770 19690`)
- **Full Responsive Design**: Mobile, tablet, and desktop ready

---

## 🚀 Running the Project

### Option 1: Static Webpage (Recommended)
Simply open `index.html` (or `Webpage.html`) directly in any web browser.

### Option 2: Java Backend Server (Optional)
Run `run.bat` or execute:
```cmd
javac DigiAdTechServer.java
java DigiAdTechServer 8443 8080 changeit
```
- **HTTPS**: https://localhost:8443
- **HTTP**: http://localhost:8080 (Auto-redirects to HTTPS)
